# ZIMZ Auto

**No Stress. Stay Active.**

Prototype ambassador-orchestration layer for GMoB / SZIMZ.

## What exists now
- `PROMPT.md` — Grotbot mission prompt and operating rules.
- `config.example.json` — example Ori and Lil Z profile configuration.
- `agent.py` — dry-run engine that prepares daily Story packages and weekly reward calculations.

## Current safety boundary
This prototype does **not** connect to Instagram, store passwords, publish Stories, or move GREEN AIPE. Those functions should be added only through an approved platform integration and an authorised treasury workflow.

## Pilot economics
- Weekly qualifying reward target: 6 GREEN AIPE.
- Basic ZIMZ Auto service fee: 2 GREEN AIPE.
- Net candidate after fee when the weekly requirement is met: 4 GREEN AIPE.
